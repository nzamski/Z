# Rank insignia: sources and licenses

Official IDF rank insignia, one set per arm (`ground/`, `air/`, `navy/`: they differ), from
Wikimedia Commons as listed on https://en.wikipedia.org/wiki/Israel_Defense_Forces_ranks,
unmodified. Fetched by `scripts/fetch-rank-insignia.sh`, which maps each file to its Commons
original. Each file keeps its license; reusing or changing them must follow it (attribution,
share-alike). Licenses: https://creativecommons.org/licenses/by-sa/3.0/ and
https://creativecommons.org/licenses/by-sa/4.0/
